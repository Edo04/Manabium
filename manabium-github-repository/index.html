BEFORE YOU DIVE IN

はじめる前に。

どんな人のための場所ですか？

理工系を学ぶ女性や、理工系分野に興味のある女性のためのコミュニティです。中高生、大学生、大学院生、既卒の方も、学年や立場に合わせて参加できます。

うまく話せるか、不安です。

最初は眺めるだけでも大丈夫です。湖では用意された言葉を選んで送れます。気になるボトルを読んだり、ノートにしおりを挟むところから始めてみてください。

名前や学校名は公開されますか？

固定の公開ユーザー名や学校名は表示しません。ただし、投稿本文やプロフィールに自分で書くと他の利用者に見えるため、個人を特定できる情報は書かないでください。

今は、どのような段階のサービスですか？

情報系の大学生2人が開発しているテスト公開段階のサービスです。実際に使っていただいた声をもとに、使いやすさと安心できる運営を整えています。
