# Manabium

Manabiumは、理工系分野を学ぶ女子学生を対象としたコミュニティWebアプリです。

理工系女子学生が、大学生活や就職活動、インターンシップなどについて気軽に情報交換できる場所を作ることを目的として開発しています。

## Features

### ボトルメッセージ
匿名で質問や相談を投稿し、他のユーザーと交流できる機能です。

### 企業ボトル
企業から学生に向けて、インターンシップやイベントなどの情報を届けるための機能です。

### ブログ
理工系女子学生に役立つ情報や体験談などを掲載するための機能です。

### スカウト
企業と学生をつなぐことを想定した機能です。企業側から学生へアプローチできる仕組みを検討しています。

## Background

理工系分野では、同じ属性や立場の学生と交流したり、進路やキャリアについて相談したりする機会が限られていると感じたことから、Manabiumの開発を始めました。

単なる質問掲示板ではなく、学生同士の交流に加えて、インターンシップ情報や企業との接点も得られるサービスを目指しています。

## Development

Manabiumは2名で企画・開発を進めています。

### Development / Engineering
主に以下を担当しています。

- Webアプリケーションの設計・実装
- フロントエンドの実装
- バックエンド処理の実装
- Supabaseを利用した認証・データベースの構築
- 機能追加
- バグ修正・改善

実装ではCodexなどのAIコーディングツールも積極的に活用し、生成されたコードについて動作確認や修正を行いながら開発しています。

### Planning / Research / Operations
共同開発者は主に以下を担当しています。

- サービスの企画・アイデア検討
- 競合サービスの調査
- 実装した機能の動作確認・フィードバック
- 支援者や関係者とのメール対応
- 運営に関する検討

企画、開発、検証を分担しながらサービスを制作しています。
